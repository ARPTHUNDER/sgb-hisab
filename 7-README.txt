SGB Hisab v5.2 - installable phone app

Upload every file in this folder to the ROOT of the public GitHub Pages site over HTTPS. Keep index.html, manifest.webmanifest, sw.js, and all three PNG icons together with these exact names.

Install on papa's Android phone
1. Open the HTTPS app link in Chrome.
2. Tap Install App on the page, or tap Chrome's three dots (⋮).
3. Choose Install app (or Add to Home screen) and confirm.
4. Open SGB Hisab from its new home-screen icon.

The app works offline after its first successful online load. Hisab data stays in the browser on this phone; it does not sync to other phones. Clearing Chrome/site data can erase the data, so use the app's backup regularly. Installing on another phone starts with separate data.

Files: index.html (PWA home), SGB_Hisab_v5_2_Installable.html (same standalone app copy), manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png. The store's circular logo is used in the app favicon and app icons.
